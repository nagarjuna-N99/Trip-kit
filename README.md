# Trip Kit

Offline-capable trip companion for a Taiwan, Hong Kong and Macau trip (Dec 16, 2026 to Jan 5, 2027).

- `site/` is the whole app: one page, a service worker for offline use, and install files.
- Live weather and exchange rates load when online and stay saved for offline use.
- Booking numbers, addresses and private details are not in this repo. They are pasted into the app on the phone and stay in that browser only.

Deployed with GitHub Pages (Settings > Pages > Source: GitHub Actions).
